## Personal Portfolio Website — Nathan Pacey

This repository contains the source code for my personal portfolio website. The site highlights my academic background, research experience, and projects.

### Run locally

From the repository directory, start a local web server:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000 in your browser. Stop the server with `Ctrl+C`.
